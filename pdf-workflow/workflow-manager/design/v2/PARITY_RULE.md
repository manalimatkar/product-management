# Workflow Manager — light/dark parity rule

Every dark/light pair in this project (Mapping Report, Workflow Dashboard, Workflow Settings Dialog, and any future page) must stay in lockstep:
- Identical behavior, data, structure, spacing, padding, fonts, and all view elements (table/card views, edit panels, dialogs, toasts, menus, filters).
- The ONLY difference allowed between a dark file and its light counterpart is color (theme tokens/palette).
- Any change made to one theme's layout/behavior/content must be mirrored in the other immediately.
