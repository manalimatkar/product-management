## 3. Epic: `EPIC-001` -- Cart Item Management

Lets a shopper manage the contents of their cart with confidence -- removing unwanted items safely, applying discounts with clear feedback, and never being stranded by an empty cart.

### Story `STORY-001`: Remove an Item from the Cart

**As a** shopper, **I can** remove an item I no longer want from my cart, with a confirmation step first, **so that** my cart reflects what I actually intend to buy and I don't lose an item by accident.

- **Traces to:** `BR-001`, `BR-002`
- **Independently valuable:** yes -- a shopper can use this capability on its own, regardless of coupons or the empty-cart path.

#### Acceptance Criteria

```text
Given a cart with at least one item
When the shopper clicks Remove on an item
Then the product shows a confirmation prompt
And the item is not removed until the shopper confirms

Given the confirmation prompt is shown for an item
When the shopper clicks Confirm Remove
Then the item is removed from the cart
And the cart's displayed totals are updated to reflect the removal
```

- Additional cases: recovery (cancel leaves the cart unchanged) is represented; validation, loading, permissions are not established in source.

### Story `STORY-002`: Apply a Coupon Code

**As a** shopper, **I can** apply a coupon code to my cart, **so that** I can see a validated discount reflected in my totals, or a clear reason it didn't work.

- **Traces to:** `BR-003`
- **Independently valuable:** yes -- coupon application is usable whether or not the shopper has removed any items.

#### Acceptance Criteria

```text
Given the shopper has entered a coupon code
When the shopper clicks Apply and the code is valid
Then a confirmation is shown
And the discount is applied to the cart totals

Given the shopper has entered a coupon code
When the shopper clicks Apply and the code is invalid
Then an inline error is shown
And the coupon input keeps focus
```

- Additional cases: error and recovery (retry after inline error) are represented; exact valid-code format is pending `DEC-002`.

### Story `STORY-003`: Return to Shopping from an Empty Cart

**As a** shopper, **I can** see a clear message and a way back to browsing when my cart is empty, **so that** I'm not stuck with nowhere to go.

- **Traces to:** `BR-004`
- **Independently valuable:** yes -- this is the shopper's only path forward when the cart has nothing in it.

#### Acceptance Criteria

```text
Given the cart contains no items
When the shopper views the cart
Then the product displays a message indicating the cart is empty
And the product offers a way to continue shopping
```

- Additional cases: not applicable beyond the empty state itself.
